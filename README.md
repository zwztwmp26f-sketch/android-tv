# Liquid Launcher (Android TV)

## Сборка
1. Установите Android Studio (Koala или новее) и JDK 17.
2. File > Open > папка LiquidLauncher, дождитесь синхронизации Gradle.
3. Build > Build APK(s). Файл: app/build/outputs/apk/debug/app-debug.apk
   Из консоли: ./gradlew assembleDebug (если нет gradlew: gradle wrapper, затем команда выше).

## Установка на ТВ
Включите «Отладка по USB/сети» на ТВ, затем:
  adb connect IP_ТВ:5555
  adb install -r app-debug.apk
Либо скопируйте APK на флешку и откройте файловым менеджером.

## Назначение домашним экраном
- Попробуйте: adb shell cmd package set-home-activity app.liquidtv.launcher/.MainActivity
- Или кнопка Home: система может предложить выбрать лаунчер «Всегда».
- На Google TV / Android TV 12+ замена штатного экрана часто запрещена. Тогда запускайте
  «Liquid Launcher» из списка приложений или назначьте его на кнопку через настройки пульта/приложения-перехватчики.

## Первый запуск
Панель пуста. Нажмите стрелку, OK на плитке «Настройки» и добавьте приложения.
Свои обои: положите jpg/png/webp в Android/data/app.liquidtv.launcher/files/wallpapers.

## Известные ограничения
- Размытие фона за стеклом пока не реализовано: панели полупрозрачные с бликом.
- Цвет часов не подстраивается под обои (белый с тенью).
- Встроенные обои сейчас градиенты, фото-коллекцию с лицензиями нужно добавить.
- Заставка внутри лаунчера (не системный Daydream).
- Выбор города для погоды в UI пока нет (Красноярск по умолчанию, Prefs.lat/lon).
- Код не компилировался и не тестировался на устройстве.
