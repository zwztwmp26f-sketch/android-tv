# Liquid Launcher (Android TV) v0.3

## Сборка
- Android Studio (JDK 17): File > Open > папка LiquidLauncher > Build APK(s).
- Или GitHub Actions (build.yml из инструкции): запускает gradle assembleDebug.

## Установка
Старую версию сначала удалить (подпись debug-ключа меняется между сборками GitHub).
  adb install app-debug.apk   или Downloader на ТВ.

## Домашний экран
adb shell cmd package set-home-activity app.liquidtv.launcher/.MainActivity
На Google TV / Android TV 12+ замена штатного экрана может быть запрещена.

## Управление
- Любая стрелка: показать панель. Вверх/вниз при открытой панели: смена обоев.
- OK: запуск. Долгое OK на значке: режим перестановки (влево/вправо, OK — готово).
- Меню на пульте: настройки. Назад: скрыть панель.

## Обои
Положите jpg/png/webp в Pictures/Wallpapers (память ТВ) или в папку Wallpapers на флешке.
Нужно разрешение на чтение фото (запрашивается при запуске).
Встроенных обоев нет: без фото фон тёмный.

## Ограничения
- Размытие только на Android 12+ (на старых полупрозрачное стекло). На слабых ТВ можно выключить.
- Плитки HDMI зависят от прошивки ТВ, на части устройств не запускаются.
- Заставка внутри лаунчера, не системная.
- Код не компилировался и не тестировался на устройстве.
